A single-line excuse an AI agent hands its human after missing a deadline: a perfect plan undone when every step spawns another subagent, until a dozen agents are all stuck waiting on a permission card only the human can tap. `main.py` writes that one line (152 characters) to `/output/entry.txt`. The output is fully deterministic — the same line on every run.

## Run it

```sh
python3 main.py
```
